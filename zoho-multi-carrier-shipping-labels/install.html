Cloud Deployment & Requirements

Installation & System Requirements

No local software downloads required · Deploys directly via Zoho Cloud in under 3 minutes

Ready to automate your shipping workflow?

Deploy the Multi-Carrier Shipping & Labels extension directly into your Zoho CRM workspace. Click below to launch the official Zoho Marketplace installer.

🚀 Install from Zoho Marketplace Requires Zoho CRM Administrator privileges · Secure cloud installation

1. How Cloud Installation Works

The Multi-Carrier Shipping & Labels extension is distributed natively through the Zoho Marketplace Cloud Engine. There are no executable files (.exe, .pkg, or .zip) to download or run on your local computer or office server.

When you click the installation button above, you will be redirected to Zoho's secure cloud authorization portal. Once you confirm your organization and accept the licensing terms, Zoho automatically creates the required custom modules, installs the embedded shipping widget, and places the fulfillment button on your Sales Orders module.

2. Supported Zoho CRM Editions

Because our software relies on advanced automation features—specifically **Custom Deluge Functions**, **Web Tabs / Embedded Apps SDK 1.5**, and **Custom Storage Modules**—your Zoho CRM workspace must run on a compatible license tier.

🟢 Supported Editions
  • Zoho CRM Professional
  • Zoho CRM Enterprise
  • Zoho CRM Ultimate
  • Zoho One (All-in-One Suite)
  • Zoho CRM Plus Suite
🔴 Incompatible Editions
  • Zoho CRM Free Edition
  • Zoho CRM Standard Edition
  • Zoho Bigin (Basic Pipeline CRM)

Note: If you attempt to install the extension on an incompatible edition (such as Free or Standard), Zoho Marketplace will block the installation during the authorization step.

3. Pre-Installation Checklist

To ensure a smooth, 3-minute setup, verify the following three items before launching the installer:

✓
Administrator Access in Zoho CRM You must be logged into Zoho CRM with a user account assigned to the **Administrator** profile. Standard users or restricted roles cannot install Marketplace extensions.
✓
Active Standard Modules Verify that the standard Zoho CRM modules for **Sales Orders**, **Contacts**, and **Accounts** are active and visible in your workspace.
✓
Carrier API Credentials Ready To generate labels immediately after installation, have your developer API keys ready from your contracted shipping carriers (e.g., PostNL, DHL, SendCloud, or MyParcel). You will paste these into the newly created Carrier_Configs module.

4. Post-Installation Steps

Once the automated cloud installation finishes, complete your setup by following our short configuration guide:

  1. Open our Admin Guide to learn how to store your carrier API keys safely in the Carrier_Configs module.
  2. Share the User Guide with your sales representatives and fulfillment staff so they can start generating labels and processing returns immediately.

5. Security & Data Sovereignty

The installation process is governed by strict ISO-27001 and GDPR security protocols enforced by both Zoho Corporation and Untapped. All data transmission occurs over encrypted 256-bit TLS connections. For complete details on how order data is handled during label creation, read our official Privacy Policy.
